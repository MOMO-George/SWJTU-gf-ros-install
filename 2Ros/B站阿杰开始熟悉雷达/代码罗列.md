### 1、软件包启蒙

```bash
mkdir catkin_ws
cd catkin_ws
mkdir src
cd src
git clone https://github.com/6-robot/wpr_simulation.git#经典永不过时
cd wpr_simulation/scripts/
./install_for_noetic.sh #先把必要的依赖都装好
cd ~/catkin_ws/
catkin_make
source devel/setup.bash 
roslaunch wpr_simulation wpb_simple.launch #经典simple
rosrun rqt_robot_steering rqt_robot_steering 
#至于修改.bashrc，自行选择，不常用的建议先别改，多有意识的去source下，有助于你的开发。
```
