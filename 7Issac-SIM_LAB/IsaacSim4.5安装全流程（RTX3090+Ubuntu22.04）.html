Isaac Sim 4.5安装全流程（RTX 3090+Ubuntu 22.04）

本文记录我在NVIDIA RTX 3090+Ubuntu 22.04环境下安装Isaac Sim 4.5的完整过程。安装过程中我踩了不少坑，包括ROS冲突、资产下载失败、驱动版本过低等，花了不少时间才全部解决。因此，我整理了这篇安装指南，希望能帮助大家少走弯路。

一、准备工作

1.硬件要求：

Isaac Sim官方的硬件要求如下：

提示：

（1）如果显卡显存<16GB，运行大型场景时可能会卡顿。

（2）硬盘空间一定要预留≥200GB，因为Isaac Sim本体和资产包加起来非常大。

（3）建议准备U盘或双系统，方便传输Isaac Sim Assets。

2.系统环境

Ubuntu版本：20.04/22.04（推荐22.04）

lsb_release -a

CUDA版本：12.2以上

nvcc --version

驱动版本：≥535

nvidia-smi

可以在官网下载Isaac Sim Compatibility Checker文件检查系统硬件和环境是否满足Isaac的环境要求。在Download Isaac Sim — Isaac Sim Documentation下载Isaac Sim Compatibility Checker并解压。

打开解压后的文件夹，并在文件夹中打开终端。输入

./omni.isaac.sim.compatibility_check.sh

检查环境是否满足要求。

二、升级系统与CUDA

1.升级Ubuntu

Isaac Sim 4.5最低要求是Ubuntu 20.04，我的系统原本是Ubuntu 18.04，需要升级。

参考以下教程，我先将系统升级到Ubuntu 20.04，再升级到Ubuntu 22.04。

ubuntu18.04 升级到ubuntu22.04版本_ubuntu18.04升级到22.04-CSDN博客

注意：

（1）Ubuntu无法直接从18.04升级到22.04，必须先升级到Ubuntu 20.04，再升级到Ubuntu 22.04。

（2）升级过程中，我遇到了升级前安装的ROS与升级目标系统冲突导致系统无法升级的问题，卸载ROS之后问题解决，成功完成系统升级。（ROS或ROS2可以放心卸载，下文会重新安装ROS2）

（3）在升级到Ubuntu 22.04后，注意关闭自动升级，防止系统自行升级到24.04。

2.安装CUDA

Isaac Sim对CUDA版本有要求，推荐使用CUDA 12.2（或更高），我的CUDA版本是CUDA 12.8。

安装完成后验证：

nvcc --version

三、安装NVIDIA驱动

根据官方要求，驱动需≥535.129.03。

我升级到了575.57.08（这是我的系统推荐版本，可以根据自己的系统情况自行选择）。

查看系统推荐驱动：

ubuntu-drivers devices

推荐安装的驱动通常标有recommended：

升级驱动：

sudo apt update
sudo apt install nvidia-driver-575  //575可以改成其他系统推荐版本

重启后验证：

nvidia-smi

四、安装ROS2 Humble

1.官方安装方法

官方下载参考：Ubuntu (deb packages) — ROS 2 Documentation: Humble documentation

运行：

sudo apt update
sudo apt upgrade
sudo apt install ros-humble-desktop

安装时间较长。

2.更快的选择

安装好之后才想起来可以使用鱼香ROS脚本快速安装，效率高很多。但是我已经安装好了，所以没有尝试。注意安装的是ROS2 Humble。

参考链接：

Ubuntu安装ROS(2) —— 安装ROS2 humble(最新、超详细图文教程，包含配置rosdep)_ros2安装-CSDN博客

五、安装Isaac Sim

1.下载Isaac Sim程序

Isaac Sim官方下载地址：

Download Isaac Sim — Isaac Sim Documentation

下载Isaac Sim 4.5 Linux版：

下载较慢，但最终成功完成。

用以下代码解压并打开Isaac Sim：

mkdir ~/isaacsim
cd ~/Downloads
unzip "isaac-sim-standalone@4.5.0-rc.36+release.19112.f59b3005.gl.linux-x86_64.release.zip" -d ~/isaacsim
cd ~/isaacsim
./post_install.sh
./isaac-sim.selector.sh

ROS Bridge Extension选择isaacsim.ros2.bridge，

Use Internal ROS2 Libraries选择humble，

单击START，第一次启动时间较长。

此时Isaac Sim能够启动，但由于首次启动Isaac Sim程序会尝试从AWS下载约100GB的资产(Assets)文件，国内访问失败，无法正常使用Isaac Sim官方资产，且终端报错。接下来我们将下载本地Isaac Sim Assets。

2.下载本地Isaac Sim Assets

从夸克网盘下载资产。由于Ubuntu无法安装夸克网盘，建议在Windows中下载并存入U盘中，再用U盘下载到Ubuntu中。资产总大小约100GB，夸克网盘下载可能需要数小时。

下载链接：夸克网盘分享

3.配置本地资产路径：

参考链接：Setup Tips — Isaac Sim Documentation

在终端输入以下代码，将下载的资产解压。

mkdir ~/isaacsim_assets
cd ~/Downloads
unzip "isaac-sim-assets-1@4.5.0-rc.36+release.19112.f59b3005.zip" -d ~/isaacsim_assets
unzip "isaac-sim-assets-2@4.5.0-rc.36+release.19112.f59b3005.zip" -d ~/isaacsim_assets
unzip "isaac-sim-assets-3@4.5.0-rc.36+release.19112.f59b3005.zip" -d ~/isaacsim_assets

解压后，修改配置文件：

找到Isaac Sim的下载目录，如/home/<username>/isaacsim，

找到/home/<username>/isaacsim/apps/isaacsim.exp.base.kit，用记事本打开，

并在最后加入以下内容（注意要把所有<username>替换为自己的用户名）：

[settings]
persistent.isaac.asset_root.default = "/home/<username>/isaacsim_assets/Assets/Isaac/4.5"
exts."isaacsim.asset.browser".folders = [
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/Robots",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/People",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/IsaacLab",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/Props",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/Environments",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/Materials",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/Samples",
    "/home/<username>/isaacsim_assets/Assets/Isaac/4.5/Isaac/Sensors",
]

路径配置完成后，Isaac Sim能正确加载Assets。

六、运行验证

重启电脑，用以下命令行启动Isaac Sim（注意要把<username>替换为自己的用户名）：

cd ~/isaacsim
./isaac-sim.sh --/persistent/isaac/asset_root/default="/home/<username>/isaacsim_assets/Assets/Isaac/4.5"

终端提示Isaac Sim Full App is loaded.

Isaac Sim成功启动，并成功加载Assets。虽然有部分warning，但功能不受影响。

到这里，Isaac Sim安装完成。

七、总结与经验

（1）安装Isaac Sim的推荐顺序：Ubuntu→CUDA→驱动→ROS2→Isaac Sim程序→Isaac Sim Assets；

（2）国内用户最好提前准备好本地资产包，否则无法运行。

写下这篇安装指南的过程让我自己彻底理解了Isaac Sim的安装逻辑，也希望帮助大家解决一些问题。后续我将继续记录如何安装Isaac Lab，以及如何利用Isaac Sim进行强化学习。
