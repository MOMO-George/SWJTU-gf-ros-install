Isaac Lab安装全流程（RTX 3090+Ubuntu 22.04+Isaac Sim 4.5）

Isaac Lab安装指南（Ubuntu 22.04+RTX 3090）
Isaac Sim 专栏收录该内容
3 篇文章
订阅专栏

在上一篇文章中，我已经完成了Isaac Sim的安装。

由于需要利用Isaac Sim进行强化学习，在已经安装好的Isaac Sim的基础上，我还需要下载安装Isaac Lab。安装过程中，我参考了翻译版的NVIDIA Isaac Lab官方文档，并结合自己的踩坑经验整理出以下安装流程。

官方提供三种安装方式：pip安装、二进制安装和高级安装，我选择的是二进制安装。

一、克隆Isaac Lab

最初我使用了SSH地址进行克隆，但SSH地址无效，改用HTTPS地址后克隆成功：

​git clone https://github.com/isaac-sim/IsaacLab.git

二、创建Isaac Sim符号链接

在已安装的Isaac Sim根目录和Isaac Lab目录的 _isaac_sim 之间建立符号链接，以便Isaac Lab正确调用Isaac Sim模块：

cd IsaacLab
ln -s /home/<username>/isaacsim _isaac_sim

三、配置Conda环境（可选，但推荐）

虽然此步骤可以跳过，并直接使用Isaac Sim自带的Python环境，但还是建议执行——该过程会自动安装Isaac Lab运行所需的全部依赖，省去了手动安装的麻烦。

使用以下命令创建Conda环境：

./isaaclab.sh --conda  # or "./isaaclab.sh -c"

如果需要自定义环境名，也可以（将my_env改成自定义的环境名）：

./isaaclab.sh --conda my_env  # or "./isaaclab.sh -c my_env"

创建后激活环境

conda activate env_isaaclab  # or ”conda activate my_env”

四、安装Isaac Lab

使用apt安装依赖：

sudo apt install cmake build-essential

安装Isaac Lab：

./isaaclab.sh --install # or "./isaaclab.sh -i"

上述代码将按默认设置安装所有学习框架。如果想只安装特定框架，可以将框架的名称作为参数传递。例如，为了只安装rl_games框架，可以运行：

./isaaclab.sh --install rl_games

五、验证Isaac Lab安装

使用isaaclab.sh运行测试脚本：

./isaaclab.sh -p scripts/tutorials/00_sim/create_empty.py

或在Conda环境中直接运行Python：

python scripts/tutorials/00_sim/create_empty.py

如果看到仿真环境正常启动，并显示具有黑色视口的窗口，说明安装成功。

在终端上按Ctrl+C，退出脚本。

六、配置Isaac Assets

安装好Isaac Lab后，在训练机器人之前，必须先配置Isaac Assets，否则无法正常使用Isaac Sim官方资产。

在安装Isaac Sim时，我已经下载了本地Isaac Assets（下载方式见上一篇文章）。

用以下命令配置Isaac Assets之后，可以开始训练机器人。

echo 'export ISAACSIM_ASSETS_ROOT="/home/l/robot/isaacsim_assets/Assets/Isaac/4.5"' >> ~/.bashrc
source ~/.bashrc

七、训练一个机器人

执行以下命令快速训练一只蚂蚁走路：

无头模式（--headless）：适合快速训练，无图形界面加载，速度更快：

./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py --task=Isaac-Ant-v0 --headless

可视化模式（无需--headless）：训练过程中可观看仿真画面：

./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py --task=Isaac-Ant-v0

八、额外依赖问题（补充说明）

安装好Isaac Lab后，再次运行Isaac Sim可能会看到许多因Isaac Sim的Python环境缺少Isaac Lab所需依赖导致的报错。

这些报错不影响Isaac Sim的正常运行，如果想消除它们可以在Isaac Sim自带的Python环境中安装缺失的库。

注意确保CUDA版本与Isaac Lab虚拟环境中保持一致（例如我的环境是CUDA 12.8）：

/home/<username>/isaacsim/kit/python/bin/python3 -m pip install --upgrade pip
/home/<username>/isaacsim/kit/python/bin/python3 -m pip install \
  torch torchvision torchaudio --extra-index-url https://download.pytorch.org/whl/cu128 \
  pillow numpy scipy matplotlib tqdm \
  hydra-core gym==0.26.2 gymnasium \
  pyquaternion shapely transforms3d \
  opencv-python transforms3d

（注意要把<username>替换为自己的用户名）
