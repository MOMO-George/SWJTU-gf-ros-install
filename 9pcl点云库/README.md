安装PCL

```bash
sudo apt install python3-pip # 安装pip和Serial
pip install pyserial

sudo apt-get install -y python3-scipy # 安装scipy

sudo apt-get install libpcl-dev pcl-tools # 安装PCL
sudo apt install libboost-all-dev libflann-dev libvtk7-dev libqhull-dev
sudo apt install ros-noetic-pcl-ros
sudo apt install python3-pcl
```
